# MHub

> MHub is a Malaysian property-technology (proptech) platform by TRB Ventures Sdn Bhd, backed by 500 Global. It gives real-estate developers an integrated system to manage the full new-property sales cycle — from launch and booking through billing, collections, accounting, compliance (HIMS/KPKT and LHDN e-invoicing), and handover. MHub operates a developer portal and an authentication-gated REST API for platform integrations.

This llms.txt was generated by the API Evangelist enrichment pipeline from the MHub public web surface and the API Evangelist catalog. MHub's public API surface is authentication-gated; no public OpenAPI/Swagger definition was available at generation time.
